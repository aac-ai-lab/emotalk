# Quadros (Frame Semantics / Fillmore) no Emotalk

**Idioma / Language:** [Português (Brasil)](README.html) | [English](../en/FRAME_SEMANTICS.html)

O Emotalk inclui um recurso **Quadros** inspirado em **Frame Semantics** (Charles J. Fillmore) e no projeto **FrameNet**: quadros semânticos com vários papéis (frame elements) que o utilizador preenche com palavras do vocabulário. A aplicação vocaliza a frase completa.

## O que é Frame Semantics (Fillmore)

Na linguística, **Frame Semantics** descreve o significado das palavras em termos de **quadros semânticos**: situações tipo com participantes e papéis (frame elements). Por exemplo, o quadro «Dar» envolve quem dá (Donor), o que é dado (Theme), e a quem (Recipient). O verbo «dar» evoca esse quadro. O **FrameNet** (UC Berkeley) é uma base lexical que mapeia palavras para quadros e anota frases com os papéis preenchidos.

No Emotalk, os Quadros permitem construir frases completas escolhendo um quadro (ex.: Dar, Comer, Ir, Querer) e preenchendo cada papel com uma palavra compatível (filtrada por tipo semântico: Quem, O quê, Onde, Como).

## Como ativar e usar

1. **Ativar:** Configurações → **Quadros (Fillmore)** → marcar «Ativar Quadros (Frame Semantics / Fillmore)» → **Salvar**.
2. O botão **Quadros** (🖼️) aparece na barra lateral (entre Moldes e Configurações).
3. Carregue em **Quadros** → escolha um quadro na lista (Dar, Comer, Ir, Querer, Estar, Ver).
4. Para cada papel do quadro, escolha uma palavra na grelha (ex.: «Quem dá» → pessoas; «O quê (é dado)» → objetos; «A quem» → pessoas).
5. A pré-visualização mostra a frase (ex.: «Mãe dá maçã a João»). Carregue em **Falar frase** para vocalizar e registar no histórico.

## Quadros disponíveis

| Quadro | Papéis (frame elements) | Exemplo de frase |
|--------|-------------------------|------------------|
| **Dar** | Quem dá, O quê (é dado), A quem | ___ dá ___ a ___ |
| **Comer** | Quem come, O quê (comida) | ___ come ___ |
| **Ir** | Quem vai, Para onde | ___ vai ___ |
| **Querer** | Quem quer, O quê (desejado) | ___ quer ___ |
| **Estar (estado)** | Quem, Como (estado) | ___ está ___ |
| **Ver** | Quem vê, O quê (visto) | ___ vê ___ |

As palavras mostradas em cada passo são filtradas pelo papel semântico (Quem → categorias de pessoas; O quê → objetos; Onde → lugares; Como → descrever/emoções), alinhado com o Colourful Semantics e o vocabulário da prancha.
