# Colourful Semantics in Emotalk

**Language / Idioma:** [English](README.html) | [Português (Brasil)](../pt-br/COLOURFUL_SEMANTICS.html)

Emotalk applies **Colourful Semantics** to the communication board: categories and words are colour-coded by their role in the sentence (Who, What doing, What, Where, When, Describing). This supports sentence structure and language development.

## Semantic roles and colours

| Role | Colour | Categories in Emotalk |
|------|--------|------------------------|
| **Who** | Orange | people (pessoas) |
| **What doing** | Yellow | activities (atividades), actions (ações) |
| **What** | Green | drinks, snacks, food, body, clothes, kitchen, school, animals, technology, plants, sports, transport, health, hygiene |
| **Where** | Blue | places (lugares), home (casa) |
| **When** | Brown | weather/time (tempo) |
| **Describing** | Purple | describe (descrever), emotions (emoções), colours (cores) |

## Where colours appear

- **Category grid:** Each category card has a coloured left border and light background.
- **Word grid:** When a category is opened, words use the same colour as the category.
- **Sentence bar:** Each pictogram in the phrase bar keeps its semantic colour, so the phrase can be “read” by role (Who + What doing + What + Where…).

## Legend

The **Settings** (🔧) modal includes a legend with all roles and colours. The semantic role of each item is stored with the phrase in localStorage, so colours are restored when the app is reopened.

## References

Colourful Semantics is a speech and language therapy approach that uses colour-coded symbols to teach sentence structure. It is often used with AAC. Emotalk maps its categories to these roles so the board supports both vocabulary and sentence building.
