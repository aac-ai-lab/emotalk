# Core icons (MINSPEAK / Semantic compaction) in Emotalk

**Language / Idioma:** [English](README.html) | [Português (Brasil)](../pt-br/MINSPEAK.html)

Emotalk offers a **Core icons** mode inspired by **MINSPEAK** (Bruce Baker) and **semantic compaction**: the first screen shows a small set of multi-meaning icons; tapping an icon shows the words in that group — 2-tap access instead of browsing many categories.

## What is MINSPEAK / Semantic compaction

**MINSPEAK** is a semantic compaction system used in AAC: multi-meaning icons are combined in short sequences (2–3 taps) to produce many words with few icons on screen. It reduces the need to switch screens and supports motor-plan automatisation. Systems such as **Unity** and **LAMP** use this approach.

In Emotalk, Core icons mode groups vocabulary categories into **6 core icons**: People, Actions, Food & drink, Things, Places, Describe/Feel. The first screen shows only these 6 icons; tapping one shows all words from that group’s categories. The user selects a word and it is added to the phrase bar (and can be spoken), same as in category mode.

## How to enable and use

1. **Enable:** Settings → **Core icons** → check «Use core icons (MINSPEAK / Semantic compaction)» → **Save**.
2. The main screen then shows **6 icons** instead of the full category list.
3. Tap an icon (e.g. Food & drink) → all words from drinks, snacks and food categories appear.
4. Tap a word to add it to the phrase bar (and hear the word). Use **Speak** to vocalise the phrase, **Clear** to clear the bar, **Home** (🏠) to return to the 6 core icons.

## Core icons in Emotalk

| Icon | Name | Grouped categories |
|------|------|---------------------|
| 👥 | People | people |
| ▶️ | Actions | activities, actions |
| 🍽️ | Food & drink | drinks, snacks, food |
| 📦 | Things | body, clothes, kitchen, school, animals, technology, plants, sports, transport, hygiene, health |
| 📍 | Places | places, home |
| 🌈 | Describe / Feel | emotions, describe, colours, time |

Vocabulary and phrase bar are the same as in category mode; only the first screen is reduced and word access is 2-tap (icon → word).

## Justification and references

- **Baker, B.** — MINSPEAK; semantic compaction in AAC (1980s).
- **Unity, LAMP** — Systems using multi-meaning icons and sequences.
- **AAC and speech therapy:** Fewer icons on screen, more words accessible by sequence; support for consistent motor plans.
